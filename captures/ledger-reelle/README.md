# A real Ledger Flex, on the live site

These photos are frames of a video shot on 13 October 2026: a **real Ledger Flex** (not the emulator), plugged over USB
into a laptop running Chrome on **https://netout.tech** ("Real Ledger (USB)" and "My Ledger · this browser", WebHID).
The Flex runs the Ethereum app 1.22.4 built with Ledger's test key, so it reads our clear-signing descriptors. The
holder's full address is blurred on the first photo.
