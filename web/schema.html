Le coffre — la règle appliquée à chaque position

ExitVault.sol · fork de Base, bloc 50 614 000

Swaps Uniswap v4 : buy() = achat + revente intégrale simulée dans la même transaction → revert CannotExit si la sortie dépasse le mandat. Coffres ERC-4626 : enterVault() = dépôt puis retrait réels annulés + la porte du plus gros déposant (maxWithdraw contre convertToAssets).

Hors bornes → une dérogation à usage unique, liée au nombre lu (ExitWorseThanSeen sinon). sell() / exitVault() / withdraw() : le porteur reprend tout quand il veut. 32 tests, 7 suites.

Ring CLI — le secret maître

wallet-cli ring · Ledger Key Ring Protocol

scripts/ring-seal.sh scelle mcp/.mcp-key, le secret maître dont dérivent toutes les clés de compte : une seule clé à protéger, adossée à la graine de l'opérateur, révocable depuis l'appareil. ring init : un Flex en USB, une fois ; ensuite sans appareil, avec réseau.

En SaaS, le client n'a aucun secret à garder : le Ring est un outil d'opérateur — c'est la brique qu'on retirerait.

Le compte

accounts/<adresse>/

profile.json · mandate.json · bots.json · journal.jsonl (chaque ligne porte le bot) · notifications.jsonl · events.jsonl (ce que tu as fait : connexion, session, stratégie, signature, bots ajoutés et arrêtés, tours, dérogations, questions).

Prévenu quand ça déborde : webhook PDS_NOTIFY_URL, bannière et notification du navigateur. Rien ne part vers la Ledger tant que ça tient.
